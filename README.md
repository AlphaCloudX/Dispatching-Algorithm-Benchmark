# Dispatching-Algorithm-Benchmark
Working as a dispatcher, I noticed that manually locating tow trucks for members isn't efficient. I created my own dispatching algorithm that assigns calls to drivers one by one.

This program is able to simulate a day of dispatching tow trucks and create a diagnostic report of call and driver statistics:

It also uses a config file which allows for fine tuning different probabilities for events that can occur or the trucks available etc.
